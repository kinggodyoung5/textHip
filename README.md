# 책꾸

읽은 문장으로 꾸미는 나만의 책방. 초등 3~4학년 대상 독서 앱의 해커톤 시연용 화면입니다.

## 지금 동작하는 화면
1. 첫 화면: 아지트의 문
2. 문을 누르면 문이 열리고 안으로 들어가는 애니메이션
3. 방 전경
4. 책장을 누르면 책장 확대 (어린 왕자)
5. 책을 누르면 "책을 모두 읽었어요!" 메시지

방 꾸미기, 문장 스티커, 우리 반 미션, 고전의 세계, 표지 꾸미기는 버튼만 있습니다.

## 실행
- 배포 주소에서 바로 보거나, `chaekkku.html`을 내려받아 더블클릭합니다 (그림까지 한 파일에 들어 있음).
- 코드를 고친 뒤에는 `python build.py`로 `chaekkku.html`과 `assets/manifest.js`를 다시 만듭니다.

## 파일
- `index.html`, `app.js`, `style.css`: 화면
- `data.js`: 도서 목록, 독서 유형 질문, 스티커 재료 등 (다음 단계용 데이터 포함)
- `assets/`: 그림 에셋
